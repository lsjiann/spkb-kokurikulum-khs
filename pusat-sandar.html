Sandar & Pulihkan Data

Eksport semua data SPKB ke fail JSON · Import dari fail JSON · Auto-backup tempatan

Eksport Sandaran

Muat turun semua data SPKB (takwim, kehadiran, instrumen, kewangan, inventori, draf laporan) sebagai satu fail JSON. Simpan fail ini sebagai sandaran luar talian.

Disarankan: Buat sandaran setiap akhir minggu atau sebelum perubahan besar.

Pulihkan dari Fail JSON

Drag-drop atau pilih fail sandaran JSON SPKB untuk pulihkan data.

Drag fail JSON ke sini, atau klik untuk pilih
Hanya fail .json sandaran SPKB diterima
Perhatian: Pulihan akan ganti data sedia ada untuk kunci-kunci yang sama. Sandar dahulu jika ragu-ragu.

Cloud Sync (Sync Antara Peranti)

Sync data SPKB ke Google Sheets supaya boleh akses dari mana-mana peranti

Status Setup

Belum disetup. Ikuti langkah di bawah untuk aktifkan cloud sync.
Salin tampal URL deployment Apps Script yang anda buat (langkah 3 di bawah)

Langkah Setup Backend

  1. Buka projek Google Apps Script yang menjalankan SPKB (yang ada Code.gs sedia ada).
  2. Tambah fail baharu dengan nama cloud-sync.gs (File → New → Script File).
  3. Salin kod di bawah ke fail itu, kemudian klik Save (Ctrl+S).
  4. Klik Deploy → New deployment → Pilih "Web app" → Execute as: "Me" → Access: "Anyone" → Deploy.
  5. Salin URL Web App yang dipaparkan dan tampal ke kotak "URL Endpoint Sync" di atas.
  6. Klik Uji Sambungan untuk pastikan ia berfungsi.
// ====================================================
// SPKB CLOUD SYNC — Backend Module
// Letak fail ini sebagai 'cloud-sync.gs' dalam projek Apps Script
// ====================================================
const SYNC_SHEET_NAME = 'spkb_sync';

function doGet(e) {
  const action = e.parameter.action || '';
  if (action === 'sync_get_all') return _resp({ success: true, data: _getAllSyncData(e.parameter.user || 'default') });
  if (action === 'sync_get')     return _resp({ success: true, value: _getSyncValue(e.parameter.user || 'default', e.parameter.key) });
  if (action === 'sync_ping')    return _resp({ success: true, ts: new Date().toISOString() });
  return _resp({ success: false, error: 'Unknown action' });
}

function doPost(e) {
  try {
    const body = JSON.parse(e.postData.contents);
    if (body.action === 'sync_set') {
      _setSyncValue(body.user || 'default', body.key, body.value);
      return _resp({ success: true });
    }
    if (body.action === 'sync_set_bulk') {
      const items = body.items || {};
      Object.keys(items).forEach(k => _setSyncValue(body.user || 'default', k, items[k]));
      return _resp({ success: true, count: Object.keys(items).length });
    }
    return _resp({ success: false, error: 'Unknown action' });
  } catch (err) {
    return _resp({ success: false, error: String(err) });
  }
}

function _sheet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(SYNC_SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SYNC_SHEET_NAME);
    sh.appendRow(['user', 'key', 'value', 'updated_at']);
    sh.getRange(1, 1, 1, 4).setFontWeight('bold').setBackground('#1e3a5f').setFontColor('#fff');
  }
  return sh;
}

function _getSyncValue(user, key) {
  const sh = _sheet();
  const data = sh.getDataRange().getValues();
  for (let i = 1; i < data.length; i++) {
    if (data[i][0] === user && data[i][1] === key) return data[i][2];
  }
  return null;
}

function _getAllSyncData(user) {
  const sh = _sheet();
  const data = sh.getDataRange().getValues();
  const out = {};
  for (let i = 1; i < data.length; i++) {
    if (data[i][0] === user) out[data[i][1]] = data[i][2];
  }
  return out;
}

function _setSyncValue(user, key, value) {
  const sh = _sheet();
  const data = sh.getDataRange().getValues();
  const now = new Date().toISOString();
  for (let i = 1; i < data.length; i++) {
    if (data[i][0] === user && data[i][1] === key) {
      sh.getRange(i + 1, 3, 1, 2).setValues([[value, now]]);
      return;
    }
  }
  sh.appendRow([user, key, value, now]);
}

function _resp(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
Tip: Anda boleh guna projek Apps Script yang sama dengan SPKB sedia ada. Apps Script support multiple file dalam satu projek.

Notifikasi Email Automatik

Reminder mesyuarat, deadline laporan, audit SK@S — auto-email kepada GPK Kokurikulum

Konfigurasi Reminder

Jenis Reminder Aktif:

Reminder Mesyuarat JK (5 hari sebelum)
Email amaran tentang mesyuarat akan datang
Reminder Deadline PAJSK (2 minggu sebelum)
Amaran tarikh akhir input PAJSK
Reminder Audit SK@S Awal Tahun
Amaran setiap Januari untuk semakan evidens

Langkah Setup Backend Email

  1. Dalam projek Apps Script SPKB, tambah fail baharu email-reminder.gs.
  2. Salin kod di bawah ke fail itu.
  3. Klik Triggers (jam icon) → Add Trigger → Function: sendDailyReminders → Time-driven → Day timer → 7am to 8am.
  4. Reminder akan dihantar secara automatik setiap hari pagi.
// ====================================================
// SPKB EMAIL REMINDER — Backend Module
// Letak sebagai 'email-reminder.gs' dalam projek Apps Script SPKB
// Setup trigger: Daily time-driven, 7am-8am
// ====================================================
const REMINDER_CONFIG_SHEET = 'spkb_reminder_config';

function sendDailyReminders() {
  const cfg = _loadReminderConfig();
  if (!cfg.email) return;

  const today = new Date();
  const todayISO = today.toISOString().substring(0, 10);

  // 1. Mesyuarat JK reminder (5 hari sebelum)
  if (cfg.enabled_mesyuarat && cfg.tarikh_mesyuarat) {
    const days = _daysBetween(todayISO, cfg.tarikh_mesyuarat);
    if (days === 5 || days === 1) {
      MailApp.sendEmail({
        to: cfg.email,
        subject: '⏰ Reminder: Mesyuarat JK Kokurikulum ' + (days === 1 ? 'ESOK' : 'dalam 5 hari'),
        htmlBody: _emailMesyuarat(cfg, days)
      });
    }
  }

  // 2. PAJSK deadline reminder (14 hari sebelum)
  if (cfg.enabled_pajsk && cfg.tarikh_pajsk) {
    const days = _daysBetween(todayISO, cfg.tarikh_pajsk);
    if (days === 14 || days === 7 || days === 3) {
      MailApp.sendEmail({
        to: cfg.email,
        subject: '📊 Reminder: Input PAJSK dalam ' + days + ' hari',
        htmlBody: _emailPAJSK(cfg, days)
      });
    }
  }

  // 3. Audit SK@S (setiap 1 Januari)
  if (cfg.enabled_audit && today.getMonth() === 0 && today.getDate() === 5) {
    MailApp.sendEmail({
      to: cfg.email,
      subject: '🔍 Reminder: Semakan Evidens SK@S 3.2 Tahun ' + today.getFullYear(),
      htmlBody: _emailAudit(cfg)
    });
  }
}

function _loadReminderConfig() {
  const sh = _getConfigSheet();
  const data = sh.getDataRange().getValues();
  const cfg = {};
  for (let i = 1; i < data.length; i++) cfg[data[i][0]] = data[i][1];
  return {
    email: cfg.email || '',
    tarikh_mesyuarat: cfg.tarikh_mesyuarat || '',
    tarikh_pajsk: cfg.tarikh_pajsk || '',
    enabled_mesyuarat: cfg.enabled_mesyuarat !== 'false',
    enabled_pajsk: cfg.enabled_pajsk !== 'false',
    enabled_audit: cfg.enabled_audit !== 'false',
  };
}

function _getConfigSheet() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(REMINDER_CONFIG_SHEET);
  if (!sh) {
    sh = ss.insertSheet(REMINDER_CONFIG_SHEET);
    sh.appendRow(['key', 'value']);
  }
  return sh;
}

function _daysBetween(d1, d2) {
  const ms = new Date(d2).getTime() - new Date(d1).getTime();
  return Math.round(ms / 86400000);
}

function _emailMesyuarat(cfg, days) {
  return '<h2>Reminder Mesyuarat JK Kokurikulum</h2>' +
    '<p>Tarikh: <strong>' + cfg.tarikh_mesyuarat + '</strong></p>' +
    '<p>Sila pastikan: minit lepas tersedia, agenda disahkan, kehadiran AJK dimaklumkan.</p>' +
    '<p>Gunakan Modul Generator Dokumen SPKB untuk auto-jana template minit.</p>';
}

function _emailPAJSK(cfg, days) {
  return '<h2>Reminder Input PAJSK</h2>' +
    '<p>Deadline: <strong>' + cfg.tarikh_pajsk + '</strong></p>' +
    '<p>Tindakan: semak Modul Kehadiran SPKB, pastikan semua perjumpaan direkod, jana Laporan Akhir Tahun.</p>';
}

function _emailAudit(cfg) {
  return '<h2>Reminder Audit SK@S 3.2</h2>' +
    '<p>Awal tahun baharu — semak status evidens 7 aspek dalam Modul Instrumen SKPMg2 3.2.</p>' +
    '<p>Gunakan Auto-Padan SK@S untuk pautkan fail Google Drive ke evidens.</p>';
}

// Test function — boleh run untuk hantar email ujian

  if (cfg.email) {
    MailApp.sendEmail({ to: cfg.email, subject: 'SPKB Reminder Test', body: 'Sistem reminder berfungsi!' });
  }
}

Bantuan & Tentang SPKB

Tutorial ringkas · Soalan lazim · Maklumat sistem

Permulaan Pantas (Workflow Tahunan)

  1. Awal tahun (Januari): Upload data pelajar & guru ke Google Sheets. Tetapkan Takwim 3-kategori dalam Modul Kehadiran. Jana surat lantikan guru penasihat (Generator Dokumen → Bulk).
  2. Setiap minggu: Rekod kehadiran murid dalam Modul Kehadiran selepas perjumpaan.
  3. Setiap bulan: Update transaksi kewangan & inventori unit. Jana Laporan KOKUM Bulanan dari Generator.
  4. Setiap fasa (Mac, Julai, Oktober): Update evidens SK@S 3.2 dalam Modul Instrumen.
  5. Akhir tahun (November): Jana Laporan Akhir Tahun PDF. Eksport sandaran ke JSON. Hantar laporan ke PPD/JPN.

Soalan Lazim

Adakah data saya selamat?
Data localStorage disimpan dalam pelayar anda sahaja. Tidak dihantar ke mana-mana server tanpa kebenaran. Untuk perkongsian/sandaran, gunakan Eksport JSON atau aktifkan Cloud Sync.
Bagaimana jika saya tukar pelayar/komputer?
Eksport sandaran JSON dari komputer lama, kemudian Import dalam komputer baharu. Atau aktifkan Cloud Sync untuk auto-sync.
Berapa banyak data boleh disimpan?
localStorage biasanya benarkan ~5MB-10MB per domain. Untuk SPKB ini cukup untuk 5-10 tahun rekod. Sila pantau saiz di tab Status Sistem.
Bagaimana auditor PPD nak akses?
Buka SPKB di komputer anda → tunjuk modul yang relevan (Buku Pengurusan, Instrumen SK@S, Laporan Akhir Tahun). Atau eksport PDF terlebih dahulu dari setiap modul.
