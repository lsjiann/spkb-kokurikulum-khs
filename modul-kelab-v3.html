Tambah Borang / Kelab Baharu (Tanpa Kod!)

A. Tambah Borang Baharu

  1. Buka Google Sheets SPKB_Form_Registry
  2. Tambah baris baharu dengan maklumat:
// Struktur kolum Sheets: id : F08 nama : "Borang Penilaian Aktiviti" icon : "fa-star" desc : "Nilai kualiti aktiviti kelab" url : "https://forms.gle/xxx" qr : "https://qr.io/xxx" special : "false" // true = badge ungu status : "active"

3. Simpan → SPKB auto-papar borang baharu selepas "Muat Semula".

B. Tambah / Edit Kelab

  1. Buka Google Sheets SPKB_Clubs
  2. Tambah baris atau edit data sedia ada:
kod : S19 nama : "Ping Pong Wanita" kat : S ahli : 24 pajsk : 4.1 fail : 42 status : "green" // green/yellow/orange/red guru : "Pn. Tan"
💡 Tiada HTML Perlu Diedit! Semua perubahan dibuat di Sheets sahaja. Sistem baca data automatik setiap kali halaman dibuka atau "Muat Semula" diklik.
